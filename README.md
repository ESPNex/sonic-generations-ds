# SONIC GENERATIONS DS — full-conversion (base: Sonic Colors DS)

Progetto attuale: **full-conversion ROM hack**. La ROM di Sonic Colors DS viene modificata
completamente fino a diventare il più possibile identica a **Sonic Generations 3DS** (DSi,
verificata su melonDS headless). Piano completo: [PLAN.md](PLAN.md).

Il vecchio progetto (port diretto con motore custom, M0–M8) è archiviato nel branch
[`archive/direct-port`](../../tree/archive/direct-port) e resta riferimento per
decoder CGFX/AMB, RE evt/collisioni e documenti.

**Regole**: asset solo originali · consegna per ogni passo = commit + **video** (mai
screenshot) · giudice visivo = l'utente · unpack/repack ROM con strumenti Linux nativi
(ndstool), non Python.
